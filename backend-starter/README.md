# OPTIONAL C# ASP.NET Core starter

This is an optional **unverified** backend example for learning C# that exposes:

- `GET /api/products?q=niacinamide`
- `GET /api/products/{id}`
- `GET /api/compare?first=ordinary-niac&second=gg-bbomb`

After installing the .NET 8 SDK, run `dotnet run` from this folder. This is **not connected** to the deployed static website. There is no real database, authentication, analytics or production security setup here. The main website is complete as a static prototype and runs independently.
